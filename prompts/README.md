프롬프트는 세 계층으로 나눠 썼습니다.

1. **오케스트레이터 프롬프트** - 세션 시작 시 한 번. 작업을 어떻게 나누고
   검증할지에 대한 규칙입니다.
2. **Goal 프롬프트** - 큰 목표 하나당 한 건. 구현 방법 대신 결과와 제약을
   적습니다.
3. **교정 프롬프트** - 플레이 화면을 보고 증상만 한 줄로 전달한 것들입니다.
   약 200건이며 여기에는 싣지 않았습니다.
