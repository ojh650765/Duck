# Duck Mow

**▶ 지금 브라우저에서 플레이 — <https://ojh650765.github.io/Duck/>**

설치 없이 바로 실행됩니다. 데스크톱 Chrome / Edge 권장, 첫 로딩에 약 30초 걸립니다.

---

연못이 팔린다는 통보를 받은 오리가, 땅을 살 돈을 벌기 위해 잔디 깎기 대회에 나갑니다.
잔디를 깎아 **그림을 그리고**, 동물 심판들에게 채점받습니다.

## 세 개의 스테이지

| 라운드 | 이름 | 무엇을 하는가 |
|---|---|---|
| 1 | **LAWN ART** | 분필 가이드 선을 따라 잔디를 깎아 지정된 그림을 완성합니다. 채운 넓이 · 윤곽 · 삐져나간 정도 · 맵시를 심판 셋이 채점합니다 |
| 2 | **GOOSE RALLY** | 거위가 정원을 망치러 옵니다. 경쟁자 셋과 같은 마당에서, 자기 구역을 지키며 깎습니다 |
| 3 | **BLOOM RUSH** | 밤의 화단. 넓은 땅을 먼저 차지하는 쪽이 이깁니다. 가운데를 잡으면 롤러가 넓어집니다 |

세 라운드 합산으로 **GARDENER OF THE YEAR** 가 정해집니다.

## 조작

| 키 | 동작 |
|---|---|
| `W A S D` / 방향키 | 주행 · 조향 |
| `Space` | 핸드브레이크 · 드리프트 |
| `Shift` | 부스트 |
| `F` | 공중에서 확인 (라운드당 1회) |
| `E` | 경적 · 거위 쫓기 *(라운드 2)* |
| `C` | 뒤돌아보기 *(라운드 3)* |
| `Esc` | 일시정지 |

메뉴는 방향키 또는 마우스, `Enter` 로 선택합니다.

## 만든 방식

- **Unity 6 (6000.3.6f1)** · Universal Render Pipeline · WebGL 빌드
- 잔디는 텍스처가 아니라 **실제 블레이드 지오메트리**입니다. 깎이면 셰이더가 날을 눕히고, 그 결과가 컷 마스크에 기록되어 채점과 공개 화면에 함께 쓰입니다
- 목표 그림은 비트맵이 아니라 **부호 거리 함수(SDF)** 입니다. 가이드 선, 공개 윤곽, 채점 격자가 모두 같은 함수 하나를 읽기 때문에 셋이 어긋날 수 없습니다
- 하트 · 별 · 웃는 얼굴 · 물고기 · 왕관 · 새끼오리 · 버섯 · 닻 — 여덟 가지 그림

## 저장소 구성

| 경로 | 내용 |
|---|---|
| `Assets/Scripts/` | 게임 로직 |
| `Assets/Shaders/` | 잔디 · 컷 마스크 · UI 셰이더 |
| `Assets/Editor/` | 씬 빌더, 캡처 · 시뮬레이션 도구 |
| `Web/` | 배포 중인 WebGL 빌드 (GitHub Pages가 이 폴더를 서빙합니다) |
| `Docs/` | 아트 바이블, 기술 설계, 작업 기록 |

빌드는 Unity 에디터에서 `Duck/6 · Build WebGL`, 배포는 `main` 에 푸시하면
`.github/workflows/pages.yml` 이 `Web/` 를 GitHub Pages에 올립니다.
